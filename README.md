## Описание системы
Система состоит из трёх модулей:
1. Модуль выбора технологий — интерактивный опрос для рекомендации системы
2. Модуль инспекции кода — тест на поиск дефектов в коде
3. Модуль сравнительного анализа — метод взвешенной суммы (WSM)
## Инструкция по запуску
1. Откройте папку `Lab2_Variant5` в Проводнике
2. Дважды кликните по файлу `lab_system.bat`
3. В меню выберите нужный модуль (1, 2 или 3) или нажмите 4 для запуска всех подряд
